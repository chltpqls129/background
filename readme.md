# 🤸‍♂️백그라운드 생성기

두 가지 색상을 선택해 페이지의 선형 그라데이션 배경을 실시간으로 바꾸고, 적용된 CSS 값을 확인할 수 있는 간단한 웹 프로젝트입니다.

## 실행 방법

별도의 설치나 빌드 과정은 필요하지 않습니다.

1. 프로젝트의 `index.html` 파일을 브라우저에서 엽니다.
2. 두 색상 선택기를 조작하면 배경 그라데이션과 CSS 값이 업데이트됩니다.

## 프로젝트 구성

- `index.html` — 페이지 구조와 색상 선택기
- `style.css` — 페이지 및 요소 스타일
- `app.js` — 색상 입력을 받아 배경과 CSS 표시를 업데이트하는 동작

## 사용 기술

- HTML
- CSS
- JavaScript (외부 라이브러리 없음)
